Rebellion + Desertion = Curses

Part 2 — Possible modern diseases, disorders, and cancers matching the Hebrew descriptions
Deuteronomy 28:15–68 affliction terms

Companion to Part 1 (Hebrew → English disease map). This document suggests plausible modern medical correlates for each Hebrew term. Ancient writers did not use modern taxonomy; one Hebrew word often covered several conditions.

Method: Strong’s / lexicon glosses + biblical context + ancient Near Eastern medicine + modern clinical parallels. Listed items are possibilities, not confirmed ancient diagnoses.

Not medical advice. “Cancer” appears only where wasting, masses, or chronic non-healing lesions reasonably match the Hebrew description.

Affliction-by-affliction correlates

דֶּבֶר   H1698   dever — pestilence / plague

Deuteronomy 28:21

Infectious epidemics (most likely)

  • Bubonic plague (Yersinia pestis)
  • Cholera
  • Typhoid or typhus
  • Smallpox ( epidemic form )
  • Influenza pandemics
  • Measles ( epidemic )
  • Dysentery / shigellosis ( epidemic dysentery )
  • Any high-mortality epidemic where disease “cleaves” to a population

Hebrew emphasizes divinely sent epidemic judgment, not a single pathogen. Livestock pestilence (Exodus 9:3) parallels anthrax or rinderpest in other texts.

שַׁחֶפֶת   H7829   shachepheth — consumption / wasting disease

Deuteronomy 28:22

Wasting illnesses

  • Tuberculosis ( pulmonary and extrapulmonary ) — strongest single correlate; modern Hebrew shachefet still means TB
  • Advanced cancer cachexia ( lung, stomach, pancreatic, lymphoma, etc. )
  • HIV/AIDS wasting syndrome
  • Severe chronic heart failure ( cardiac cachexia )
  • End-stage COPD / emphysema with weight loss
  • Chronic parasitic load ( hookworm, schistosomiasis ) with malnutrition
  • Severe malnutrition / marasmus

Ancient authors could not distinguish TB from other wasting diseases. The term is a syndrome ( progressive emaciation, weakness, often with fever ) rather than one modern ICD code.

קַדַּחַת   H6920   qaddachath — fever / burning ague

Deuteronomy 28:22

  • Malaria ( endemic in Egypt and Canaan regions )
  • Typhoid / paratyphoid fever
  • Influenza
  • Sepsis / bacteremia
  • Brucellosis
  • Leptospirosis
  • Any sustained febrile illness paired with wasting in v. 22

דַּלֶּקֶת   H1816   dalleqeth — inflammation / inflammatory disease

Deuteronomy 28:22

  • Cellulitis and erysipelas
  • Sepsis with systemic inflammation
  • Rheumatic fever
  • Severe respiratory infection ( pneumonia )
  • Inflammatory bowel disease ( severe flare )
  • Autoimmune vasculitis
  • Osteomyelitis

Root idea: burning inflammation (deleq = burn ). Fits hot, red, swollen infectious or autoimmune processes.

חַרְחֻר   H2746   charchur — extreme burning / fiery heat

Deuteronomy 28:22

  • Hyperpyrexia ( very high fever )
  • Heat stroke / heat exhaustion ( desert climate )
  • Severe dehydration with elevated body temperature
  • Burning dysuria from urinary tract infection
  • Intense inflammatory skin eruption with burning pain

Some translations render as drought rather than bodily disease; in Deuteronomy 28:22 it sits among bodily afflictions, so fever/heat syndromes fit best.

שְׁחִין מִצְרַיִם   H7822   shchin Mitzrayim — boil(s) of Egypt

Deuteronomy 28:27 (Egypt named in this chapter)

  • Furuncles and carbuncles ( Staphylococcus aureus )
  • Cutaneous anthrax ( painful black eschar with swelling )
  • Smallpox pustules ( if historical smallpox present )
  • Impetigo / ecthyma ( deeper pustular infection )
  • Plague buboes ( if linked to epidemic context )
  • Cutaneous leishmaniasis ( chronic ulcers )
  • Chronic non-healing skin ulcers ( could include skin cancer — SCC, BCC — in modern terms, though ancients would not classify as cancer )

Recalls Exodus 9:9–11 ( festering boils on humans and animals ). Incurable in v. 27 = chronic, treatment-resistant skin disease.

עֳפָלִים   H6076   ophalim — tumors / swellings / emerods

Deuteronomy 28:27

  • Hemorrhoids ( internal / external )
  • Anal or perianal abscess / fistula
  • Inguinal or axillary lymph node enlargement ( infection or lymphoma )
  • Plague buboes ( swollen lymph nodes )
  • Rectal prolapse with swelling
  • Colorectal cancer or anal cancer ( mass / obstruction )
  • Pelvic tumors ( uterine, ovarian in women )
  • Prostate enlargement or prostate cancer ( if generalized to groin swelling )

Same root used for Philistine “tumors” in 1 Samuel 5–6 ( with rats / dysentery context ).

טְחֹרִים   H2914   techorim — hemorrhoids / anal tumors

Deuteronomy 28:27 (Qere; paired with ophalim)

  • Hemorrhoids ( grades I–IV )
  • Thrombosed external hemorrhoid
  • Anal fissure with swelling
  • Perianal hematoma
  • Rectal prolapse
  • Dysentery-related rectal inflammation ( Shigella, amoebic colitis )
  • Anal cancer or rectal adenocarcinoma ( chronic mass / bleeding )

Often merged with ophalim in English Bibles. Medical texts link to dysentery complications in ancient armies and sieges.

גָּרָב   H1618   garav — scab / scaly eruption

Deuteronomy 28:27; Leviticus 21:20; 22:22

  • Eczema / atopic dermatitis
  • Psoriasis
  • Tinea corporis / capitis ( ringworm )
  • Impetigo ( crusted scabs )
  • Scabies ( with secondary crusting )
  • Seborrheic dermatitis
  • Pityriasis rosea

Not modern nutritional scurvy ( vitamin C deficiency ) — KJV “scurvy” for garav is a misleading traditional rendering. Hebrew = itchy, scaly, scratchable skin.

חָרֶס   H2775   cheres — itch / dry eruption

Deuteronomy 28:27

  • Scabies ( intense nocturnal itch )
  • Chronic eczema
  • Contact dermatitis
  • Prurigo nodularis
  • Xerosis ( severe dry skin ) in arid climate
  • Cutaneous leishmaniasis ( dry, crusted lesions )
  • Body lice infestation ( with excoriation )

Paired with garav as overlapping dermatology: scale + itch. Distinct from tsara‘ath ( Leviticus 13 ) but same general domain.

שְׁחִין רָע   H7822   shchin ra — severe boil(s), head to foot

Deuteronomy 28:35

  • Disseminated furunculosis / carbunculosis
  • Generalized impetigo or ecthyma
  • Erythroderma ( exfoliative skin failure )
  • Severe bullous disease ( pemphigus, bullous pemphigoid )
  • Disseminated cutaneous infection in immunocompromised state
  • Metastatic skin involvement from internal malignancy ( rare modern correlate )

Same root as Egyptian boils but emphasized as total-body, incurable severity ( sole of foot to crown ).

שִׁגָּעוֹן   H7697   shigaon — madness

Deuteronomy 28:28

Psychiatric / neurological

  • Schizophrenia or schizophreniform disorder
  • Bipolar I disorder ( manic episode with psychosis )
  • Brief psychotic disorder
  • Delirium ( infectious, metabolic, post-siege )
  • Severe PTSD with dissociation
  • Neurosyphilis ( general paresis ) — if historical presence assumed

עִוָּרוֹן   H5788   ‘ivvaron — blindness

Deuteronomy 28:28

  • Cataracts
  • Glaucoma
  • Trachoma ( leading ancient cause of blindness in Near East )
  • Onchocerciasis ( river blindness )
  • Corneal scarring from infection or trauma
  • Optic neuritis / optic atrophy
  • Vitamin A deficiency ( xerophthalmia )
  • Diabetic retinopathy ( modern parallel to “failing eyes” )

תִּמְהוֹן לֵבָב   H8541   timmahon levav — confusion / bewilderment of heart

Deuteronomy 28:28

  • Delirium
  • Dementia ( Alzheimer’s, vascular dementia )
  • Severe anxiety with cognitive impairment
  • Post-traumatic stress with concentration failure
  • Metabolic encephalopathy ( dehydration, infection in siege )

מְשֻׁגָּע   H7696   meshuggah — driven mad / maddened

Deuteronomy 28:34

  • Acute stress disorder
  • PTSD ( combat / siege / atrocity witness )
  • Grief reaction with transient psychosis
  • Adjustment disorder with mixed disturbance of emotion and conduct

Triggered by “the sight of what your eyes see” — trauma-induced mental break rather than chronic psychosis alone.

מַכּוֹת … חֳלָיִם רָעִים   H4347, H2483 — great plagues and sore sicknesses

Deuteronomy 28:59

  • Any severe, prolonged epidemic or chronic disease not otherwise specified
  • Multi-organ failure syndromes
  • Hereditary degenerative conditions ( prolonged )
  • Recurrent malaria, TB, or dysentery over generations

Category language, not a single diagnosis.

כָּל־מַדְוֵה מִצְרַיִם   H4064   madveh Mitzrayim — all diseases of Egypt

Deuteronomy 28:60 (Egypt named in this chapter)

Plausible Egypt-endemic or Egypt-associated conditions ( collective )

  • Schistosomiasis ( bilharzia )
  • Malaria
  • Guinea worm ( dracunculiasis )
  • Trachoma and eye infections
  • Parasitic intestinal diseases ( roundworm, hookworm, tapeworm )
  • Skin diseases from Nile-region climate ( fungal, bacterial )
  • Boils / anthrax / glanders ( from Exodus plague context )
  • Pestilence among livestock and humans
  • Any condition Israel “dreaded” from Egyptian experience ( v. 60 )

Chapter does not itemize Exodus plagues here — only the collective “diseases of Egypt.” Do not read in frogs, lice, darkness, etc. unless another verse names them.

כָּל־חֳלִי … כָּל־מַכָּה   H2483, H4347 — every sickness and every plague

Deuteronomy 28:61

  • Open-ended: any infectious, chronic, genetic, or malignant disease known or unknown to the author
  • Includes modern categories absent from the ancient world: autoimmune disease, many cancers, genetic syndromes, novel viruses

לֵב רַגָּז   H7264   lev ragaz — trembling heart

Deuteronomy 28:65

  • Generalized anxiety disorder
  • Panic disorder
  • PTSD ( hypervigilance, startle )
  • Palpitations from arrhythmia ( atrial fibrillation, SVT )
  • Hyperthyroidism
  • Pheochromocytoma ( rare ; episodic terror + tachycardia )

כִלְיוֹן עֵינַיִם   H3631   killayon einayim — failing / wasting of the eyes

Deuteronomy 28:65

  • Cataracts
  • Age-related macular degeneration
  • Glaucoma ( progressive vision loss )
  • Trachoma complications
  • Chronic eye strain / exhaustion from grief ( functional visual decline )
  • Optic nerve atrophy

דַּאֲבוֹן נָפֶשׁ   H1671   da’avon nefesh — despair / languishing of soul

Deuteronomy 28:65

  • Major depressive disorder
  • Persistent depressive disorder ( dysthymia )
  • Complicated grief / prolonged grief disorder
  • Adjustment disorder with depressed mood
  • Existential despair in exile ( culturally framed as “soul” wasting )

Psychological / affective, not a cancer or infectious disease.
